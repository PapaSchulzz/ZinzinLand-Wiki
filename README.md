# ZinzinLand — Wiki du serveur

Site statique (GitHub Pages) du serveur Minecraft **ZinzinLand**.

➡️ **En ligne : https://papaschulzz.github.io/ZinzinLand-Wiki/**

## Contenu
- Armes sentientes (dont la Faux des Âmes) + recettes de craft
- Essence d'âme & Fiole d'âmes
- Autel & rituel des âmes (gain de vie)
- Vies & cœurs, Monnaie, Rangs
- Commandes joueurs

## Modifier le wiki
Tout tient dans deux fichiers :
- [`index.html`](index.html) — le contenu et la structure des pages
- [`style.css`](style.css) — le thème (sombre, type Minecraft)

Aucune dépendance, aucun build : ouvre `index.html` dans un navigateur pour prévisualiser,
puis `git commit` + `git push`. GitHub Pages redéploie automatiquement.

## Activer GitHub Pages (une fois)
Repo → **Settings → Pages** → *Source* : `Deploy from a branch` → branche `main` (ou `master`), dossier `/ (root)`.
